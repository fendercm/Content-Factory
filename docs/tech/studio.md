# Студия — видео на заказ

Отдельный от сериалов продукт: заказчик даёт идею, задачу или готовый текст и, по желанию, свои фото
(товар, люди, место) и логотип. Студия пишет сценарий, автор его правит, затем собирается ролик для
скачивания. В соцсети ничего не публикуется, очередь сериала не затрагивается.

Код: `agents/order_agent.py`, запуск шагов — `scripts/order_run.py`, API — `utils/api_server.py`
(раздел «Заказы»), интерфейс — страница «🎥 Студия» панели.

## Жизненный цикл заказа

```
draft ──(Написать сценарий)──▶ scripting ──▶ script_ready ──(Собрать видео)──▶ building ──▶ done
  ▲                                │ ошибка → draft                                 │ ошибка → failed
  └──────── правка брифа/сценария в панели (PUT /api/orders/<id>) ◀──────────────────┘
```

Заказ хранится в `output/orders/<id>/` (id — `YYYYMMDD_HHMMSS_xxxx`):

```
order.json         параметры, сценарий, этапы сборки (progress), результат, ошибка
files/             фото и логотип клиента (jpg/png/webp, ≤ 15 МБ, имена очищаются)
build/             озвучка, портреты героев, кадры, клипы, липсинк, субтитры
<id>.mp4           готовый ролик
```

## Параметры заказа

| Поле | Значения | Влияние |
|---|---|---|
| `brief` | текст | задача клиента; при `text_is_final=true` — готовый текст, озвучивается дословно |
| `mode` | `auto` · `scene` · `voiceover` | сценка с героями / голос за кадром (`ДИКТОР`) / выбор сценариста |
| `duration` | 15 · 30 · 60 · 90 | бюджет слов ≈ 2.3 слова/с (−15…+5 %); число кадров ≈ длительность / 3.5 |
| `aspect` | `9:16` · `16:9` | размер кадров Nano Banana и монтажа (1080×1920 / 1920×1080), вёрстка субтитров |
| `style`, `style_custom` | `cinema` · `ad` · `cartoon` · `anime` · `illustration` · `custom` | стиль кадров (английский текст в промпте) |
| `voice` | `auto` · `female` · `male` | голос диктора (Kore / Charon) |
| `music` | `auto` · `calm` · `upbeat` · `dramatic` · `none` | фоновая музыка (`music_agent`) |
| `animate` | `none` · `some` (3) · `more` (6) | сколько кадров оживить Wan 2.6 Flash |
| `subtitles`, `lipsync` | bool | субтитры по словам; липсинк до 3 реплик, где говорящий крупно в кадре |
| `files`, `logo` | имена файлов | фото — референсы в кадрах; логотип — в правом верхнем углу ролика |

## Сценарий — `write_script`

Один запрос `tier="premium"` с брифом, форматом, бюджетом слов, стилем и списком файлов клиента.
Ответ — JSON: `title`, `characters [{role, gender, visual_en, asset}]`, `lines [{role, emotion, text}]`.
`normalize_script` приводит его в порядок:
- у каждой роли из реплик есть персонаж; лишние персонажи убираются;
- голоса: диктор — по полю `voice`, герои — разные голоса Gemini своего пола
  (женские Leda/Kore/Aoede/Sulafat, мужские Orus/Charon/Puck/Fenrir); неизвестный голос заменяется;
- `asset` — только из файлов заказа;
- предупреждение, если слов заметно больше или меньше, чем нужно на длительность.

В панели сценарий правится текстом (`РОЛЬ: [эмоция] реплика`), у персонажей — голос, внешность
(английский, для кадров) и фото клиента вместо сгенерированного портрета.

## Сборка — `build`

| Этап (`progress`) | Что делает |
|---|---|
| Озвучка | ≤ 2 ролей — сцена одним запросом multi-speaker (`dialogue_voice._render_dialogue`), больше — по репликам; сбой Gemini → edge-tts |
| Герои / раскадровка | `plan_shots`: LLM делит реплики на кадры (кто в кадре, файл клиента, промпт, движение, чьё лицо говорит); `fix_shots` гарантирует покрытие всех реплик по порядку. Портрет героя — фото клиента или Nano Banana по описанию |
| Кадры | Nano Banana 2 с референсами героев и фото товара, в выбранном формате |
| Анимация | Wan — самые длинные кадры без говорящего лица |
| Липсинк | Kling Avatar: первая, самая длинная и последняя реплики, где лицо говорящего крупно |
| Монтаж | `series_assembly.assemble(size=…, logo_path=…)`, субтитры (`write_dialogue_ass(play_res=…)`), музыка |
| Проверка | `series_qa.check` — не блокирует заказ: замечания показываются в панели |

Результат (`order.result`): имя ролика, длительность, разрешение, число кадров, движок голоса,
себестоимость (кредиты KIE / 200), результат проверки. Оценка до сборки — `estimate_usd`
(кадры + портреты + анимация + липсинк); 30-секундная сценка ≈ $1.2.

## API

См. [admin_panel.md](admin_panel.md#заказы-студия). Файлы клиента передаются JSON-ом в base64
(все не-GET запросы панели — JSON, это часть защиты от CSRF).

## Ограничения

- Не больше 3 персонажей в кадре, 2 голосов в одном запросе TTS (больше — озвучка по репликам).
- Музыка — из локальной библиотеки по настроению; своей музыки клиента пока нет.
- Стоимость считается только по KIE; LLM-запросы бесплатного Gemini не учитываются.
