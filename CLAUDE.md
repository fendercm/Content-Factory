# Content Factory — контекст проекта

Контент-завод на Python (Windows): ИИ пишет сценарии, озвучивает, рисует кадры, монтирует вертикальные
ролики и публикует их. Управляется из локальной веб-панели. Подробная техдокументация — `docs/tech/`
(начни с [docs/tech/README.md](docs/tech/README.md)); менял архитектуру, API, конфиги или пайплайн —
обнови соответствующий файл там. Источник правды — код.

## Три продукта

| Продукт | Суть | Документ |
|---|---|---|
| **Сериал «Кабинет 7»** — главный | Антология: психолог Вера Соколова и новый клиент в каждой серии (≈ 55–65 с, 9:16). Сценарий → голоса по ролям → кадры с постоянной героиней → липсинк → монтаж → автопроверка → очередь → публикация | `docs/tech/series.md` |
| **Студия** | Видео на заказ: бриф + фото клиента → сценарий → ролик 9:16 или 16:9 для скачивания. Ничего не публикуется | `docs/tech/studio.md` |
| **Ролики по нишам** | Исходный пайплайн: тренды → идея → факты → сценарий диктора → сток Pexels → ролик; плюс `--format story`. Работает, но не в фокусе | `docs/tech/shorts.md` |

Остальное: `architecture.md` (процессы, слои, принципы), `configuration.md` (`.env`, провайдеры, LLM-цепочка,
конфиг сериала), `operations.md` (запуск, расписание, типовые сбои, деньги), `admin_panel.md` (страницы, задачи,
REST API), `data.md` (`pipeline.db`, файлы), `modules.md` (справочник модулей).

## Где что лежит

```
main.py                 оркестратор: --niche/--niches, --format clips|story|series, --prepare, --publish-next, --script, --resume
scheduler.py            планировщик (расписание сериалов из конфигов, ролики по нишам, сводка, аналитика, уборка)
agents/                 агенты — один модуль, одна роль (список — docs/tech/modules.md)
utils/                  инфраструктура: llm_client, providers (гейт платного), kie_client, ffmpeg, download,
                        housekeeping, log_redact, cost_tracker; api_server.py — Flask-сервер панели
admin_panel.html        панель (vanilla JS), start.bat — запуск панели
scripts/                script_lab (лаборатория сценариев), series_queue, series_setup, order_run, бенчмарки
config/series/<id>.json конфиг сериала; config/series/scripts/ — сценарии для производства
assets/series/<id>/     референс героини; assets/music, assets/sfx
output/ logs/           результаты и логи (в git не попадают); pipeline.db — SQLite-состояние
tests/                  pytest; docs/ — документация и финмодели
```

## Как запускать

```bash
py -X utf8 utils/api_server.py        # панель http://localhost:5000 (или start.bat)
py scheduler.py                       # планировщик (панель сама его поднимает, если расписание включено)
py -X utf8 -m pytest -q               # тесты: без сети и платных вызовов
```

```bash
py main.py --format series --series kabinet7 --niche "психология" --prepare 1      # собрать эпизод в очередь
py main.py --format series --series kabinet7 --niche "психология" --publish-next   # выпустить самый ранний
py main.py --niche "психология" --dry-run                                          # ролик по нише без публикации
```

Python запускай с `-X utf8` (Windows-консоль). FFmpeg/ffprobe — в `PATH`. Gemini и Telegram из РФ работают
только с VPN: без него сценарии, озвучка и safety не отрабатывают (`operations.md`, «Типовые сбои»).

## Правила работы (обязательны)

- **Платные вызовы — только с явным «да».** Перед любым платным вызовом (KIE: кадры, Wan, Kling, LLM-сценаристы
  premium/critic; ElevenLabs, Yandex и т. п.) назови пользователю модель и сумму в $ и дождись явного «да».
  По умолчанию — бесплатный путь. «Да» на один вызов не распространяется на следующие.
- **Groq не предлагать и не возвращать в цепочки.** Пользователь велел забыть о нём; выключен
  `DISABLED_PROVIDERS=groq`.
- **Текстовые плашки поверх видео (вопрос-крючок `hook_question`) забракованы автором** — не включать и не
  предлагать; у «Кабинета 7» выключен.
- **Коммиты — от автора `fendercm`.** Перед `git push` нужны ротация ключей и чистка истории (решение автора после
  аудита 2026-10-18) — не пушить без прямой просьбы.
- **Публикация и сборка — только по явному действию автора** или по расписанию, которое он включил. Панельная
  публикация требует `confirm: true`.
- `.env` не читать вслух, не печатать, не коммитить. Секреты маскируются в логах и Telegram (`utils/log_redact.py`).
- Вручную VK и Wibes (и VK Клипы) пользователь выкладывает сам: бот присылает ролик и подпись в Telegram
  (`manual_publish`). VK API-ключ не нужен.

## Ключевые соглашения

- Агенты общаются словарями/JSON, состояние — SQLite `pipeline.db`; ошибка агента — исключение вверх, шаги
  пайплайна повторяются до 3 раз, **публикация — ровно одна попытка** (повтор создал бы дубль).
- Гейты качества fail-closed: safety, фильтр тем, факт-чекер, Series QA при недоступности или браке не
  пропускают контент. `quality_scorer` при сбое → `skipped`, при низком балле блокирует.
- Сначала дешёвое и хрупкое, потом платное: озвучка (бесплатный Gemini TTS с дневной квотой) идёт до платных
  кадров KIE. Оплаченное лежит в `output/series/<run_id>/` и переиспользуется при `--resume`.
- **Любой новый вызов платного API проверяет `utils.providers.is_enabled()`.** `BUDGET_MODE=free` выключает платных
  провайдеров; для сериала и Студии KIE разрешён `BUDGET_ALLOW=kie_series`. `mark_dead()` отключает провайдера до
  конца процесса (402, квота, 401).
- LLM — только через `utils/llm_client.chat(messages, tier=...)`: tier `fast`, `quality`, `premium` (сценаристы:
  Gemini 4 Argon → GPT-6 Astra через KIE), `critic` (GPT-6 Astra → Claude Fable 5). ID моделей устаревают —
  перед сменой проверяй живой список. Gemini SDK — `google-genai`, не `google.generativeai`.
- Загрузки — через `utils/download.py` (`.part` + rename), FFmpeg — через `utils/ffmpeg.py`.
- `--dry-run` ничего не пишет в состояние (темы, эпизоды, лор).

## Сериал «Кабинет 7» — состояние на 2026-10-23

Конфиг — `config/series/kabinet7.json`, детали — `docs/tech/series.md`.

- **Аудитория 30+** (`audience`): пары, дети, стареющие родители, деньги в семье. По аналитике YouTube 77 % зрителей
  досматривают начало, но смотрят ~27 с из 60+ и уходят в середине серии — на это настроены правки ниже.
- **Темп озвучки ×1.15** (`voice_tempo`): дорожка ускоряется без смены высоты, тайминги делятся на темп.
- **Смена крупности** (`max_still: 3.0`): статичный кадр дольше 3 с режется, показы чередуют полный кадр и наезд
  на лицо. Клипы и липсинк не режутся.
- **Ритм открытий:** история раскладывается на пять открытий (`reveals`); первая реплика — странный поступок без
  объяснения, затем каждые 20–25 слов (8–10 с) новое открытие. Рамки: 100–125 слов, 10–12 реплик.
- **Сцены из жизни клиента** (`memory_1..3`): пока клиент рассказывает, на экране сама история вне кабинета
  (≈ +$0.12 на эпизод).
- **Критик — GPT-6 Astra** (tier `critic`, KIE) и **правит сам**: тем же вызовом возвращает сценарий со своими
  заменами, до 3 кругов, берётся лучшая версия. Принят — 8+ и все пункты чек-листа.
- Анимация Wan 2.6 Flash на 3 кадра, Kling 3.0 — 0 (`animated_simple: 3`, `animated_key: 0`); липсинк Kling Avatar на
  ключевых репликах; озвучка Gemini TTS без запасного голоса (`voice_fallback: none`).
- Эпизод стоит $0.8–1.7; в бриф закладывай, что понятность важнее подтекста (кто говорит и что происходит должно
  быть ясно с первого просмотра).
- **Расписание: ежедневно 19:00, YouTube** (`schedule` в конфиге, `scheduler.py`; при старте догоняет пропущенный
  выпуск). Очередь пуста — выпуска нет, придёт алерт в Telegram.
- Публикация: основная площадка (YouTube) и `also_publish` (TikTok, Instagram) — через Zernio; Wibes и VK Клипы
  пользователь выкладывает вручную (см. правила выше).
